# 库存优化技能

## 概述
基于汽车零部件的历史消耗、车型保有量、供应商交货周期和质量风险，
计算最优安全库存和补货点。

## 核心功能
1. **安全库存计算**: 基于需求波动和补货周期
2. **补货点预警**: 当库存低于再订购点时触发建议
3. **ABC分类**: 按价值/消耗量对零部件分类管理
4. **呆滞料识别**: 识别长期未消耗的车型专用件和慢周转件
5. **多仓分析**: 按区域仓、库位、预留库存和批次评估可用库存

## 使用方式
调用 inventory_warning / inventory_page 获取多仓库存，结合 order_statistics
分析消耗趋势，并使用 supplier_offer 的交货周期计算补货点。
