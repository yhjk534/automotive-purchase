# 供应商分析技能

## 概述
对汽车零部件供应商的货源适配能力、信用评级、价格水平、交付质量进行多维度分析。

## 分析维度
1. **价格对比**: 同类零部件不同供应商价格差异分析
2. **信用评级**: 供应商信用等级分布和趋势
3. **交付能力**: 按订单量、准时交付率和交货周期评估
4. **质量能力**: 按质量 PPM、质保和零件来源类型评估
5. **综合评分**: 多维度加权评分

## 使用方式
配合 MCP 工具获取数据后生成分析报告和图表。
